💠 Discord Rich Presence

When enabled, GAPI updates your Discord status to show the game you just picked — visible to all your Discord friends. Requires the Discord desktop app to be running and DISCORD_CLIENT_ID set on the server.

ℹ️ Rich Presence works via local IPC — it requires the GAPI server to be on the same machine as your Discord desktop app.
